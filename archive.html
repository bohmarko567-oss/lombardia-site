1 · Line figures — the Ossido blocker

Ossido, Notte and the blue collection are all drawn by patentsheet2.py from the same four traced views, so a collection can only hold the cars that have them. Today that is 8 of 20. Missing: t1, pagoda, mini, delorean, defender, e30, beetle, miura, giulia, stratos, cgt, 2cv.

node gen-clean.mjs <key> --go          # four-view base on flat blue (PLAYBOOK.md)
python trace-views.py <base.jpg> <key>  # -> patent-figs/<key>-{side,front,rear,plan}.png
python patentsheet2.py <key> ossido     # the sheet
python library.py                       # refresh this page
